## 1b. Trust-engine fix (2026-08-08 — evidence from 4 live API probes, Session A #3)
Lucas reported: "trust bar decreasing randomly, can't tell if my lie works." Probed the LIVE
/api/converse (Haiku via gateway, brain confirmed "haiku") with controlled states. Findings:
- **Perfect play earns NOTHING.** Turn-1 shipper lie with fully matching Grab outfit → trust −5, susp +10 — IDENTICAL deltas to the same lie in mismatched normal clothes. Turn-3 consistent, empathetic, persona-targeted lie to Cô Sáu → trust 0, susp +8. Perfect content-idea pitch to Ly (her exact weakness) → trust 0.
- **Root cause 1 — grader has no reward rubric.** SYSTEM_TEMPLATE tells the AI "Đừng dễ dãi" and feeds it the hidden state, but never defines what EARNS positive trust. Haiku plays stingy gatekeeper: −5..0 on everything. From start 30 to door threshold 75 is mathematically near-impossible → every run feels like slow random decay.
- **Root cause 2 — silent repeating penalty.** `contradiction: true` adds −5 trust +10 susp in client code (config.js) with ZERO visual cue, and can re-fire EVERY turn while the outfit still mismatches the story.
- **Root cause 3 — grader personality swaps mid-convo.** Haiku→DeepSeek→scripted fallback each grade differently; a timeout switches judges silently.
- **Root cause 4 — no feedback** (already the heart of §1): bar moves, player never told why.

**Fix (code-owned scoring — AI judges, code scores):**
- Schema change: replace free −20..20 deltas with `verdict` enum the AI is GOOD at:
  `lo_lieu` (busted) · `kha_nghi` (fishy) · `thuong` (meh) · `hop_ly` (believable) · `danh_trung` (hit my weakness). Code maps verdict → fixed deltas per difficulty tier (e.g. hợp lý = trust +10, đánh trúng = +16 & susp −4, khả nghi = susp +8, lộ liễu = trust −8 & susp +14, thường = patience −4 only). Same mapping across all 3 brains → judge swap no longer changes the math.
- Prompt gains an explicit rubric with 1 example per verdict (few-shot), incl. "một câu chuyện hợp lý, đúng vai, khớp đồ PHẢI được chấm hop_ly trở lên".
- `contradiction` penalty fires ONCE per outfit-story pair (client tracks a flag), and always surfaces visibly (NPC calls it out — prompt already asks this — plus 💭 bubble per §1).
- `?debug=1` overlay shows per-turn verdict + mapped deltas + brain badge (extends §4 item).
- Balance targets: easy house winnable in ~4 good turns, hard in ~7; tune the mapping table, never the prompt.

## 3. Conversation engine upgrades (prompt + schema, no rule changes)
- Schema adds: `thought` (string, VN/EN per language), `convo_state` (enum above), `final_test` (bool).
- **Final-test beat** (interview §8, Ace Attorney): first time AI signals invite_intent, engine does NOT open the door — it asks the AI for one "câu hỏi chốt" (e.g. "Ủa mà nãy em nói em tên gì?"); pass → door, fumble → suspicion spike. Default ON (Q-C).
- **Unexpected verification questions** (interview §2 Q7): personas told to occasionally demand specifics (employee ID, aunt's name, what was ordered).
- **Memory/contradiction catching** (Q8): full history already sent; prompt sharpened to quote the player's own earlier words when catching lies.
- **Absurd lies can work** (interview §3): committed ridiculous stories ("cháu từ tương lai") may charm LOW-suspicion NPCs (Ly especially); high-suspicion NPCs punish them. Funny > realistic.
- **Positive outfit comments** (interview §7): matching outfit to persona interests earns spoken warmth ("Áo MU hả?? Người nhà rồi!") — not just contradiction-catching.
- **Language**: system prompt + thought + STT switch vi↔en with the toggle.
